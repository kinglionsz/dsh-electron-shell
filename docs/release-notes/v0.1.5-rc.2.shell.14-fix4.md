# DSH-Desktop v0.1.5-rc.2.shell.14-fix4

## 🔧 修复内容

- 添加缺失的 sharp 依赖声明到 `manifest/harness/package.json`
- 修复 `ERR_DLOPEN_FAILED` 错误（sharp-win32-x64 模块加载失败）
- 更新 `pnpm-lock.yaml` 包含 sharp@0.35.4 版本锁定

## 📋 技术细节

**问题根因**：
- `@deepseek-ai/dsh-attachment-local@0.1.5-rc.2` 依赖 sharp ^0.35.3
- 但 `manifest/harness/package.json` 未声明此依赖
- 导致 pnpm deploy 时未安装 sharp，运行时加载失败

**修复方案**：
- 在 `manifest/harness/package.json` 的 dependencies 中添加 `"sharp": "^0.35.4"`
- 重新生成 `pnpm-lock.yaml` 确保版本锁定正确

## ✅ 构建平台

- Linux (Ubuntu 24.04) - .deb 包
- Windows (Windows 2022) - .exe 安装程序
- macOS (macOS 14) - .dmg 安装包

## 📦 安装说明

请下载对应平台的安装包进行安装。
